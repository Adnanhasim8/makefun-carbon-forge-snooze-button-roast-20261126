# Snooze Button Roast

One line roasting an alarm clock that rings at 6 AM on a Saturday — the snooze button is its witness protection program.

## How to run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (UTF-8, single line, 89 characters). Python 3.13 standard library only, no network at run time. The program asserts the gate itself: the entry is exactly one line of 1–200 non-whitespace characters.
